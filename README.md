# Abhilash Reddy — Portfolio

**Live site: https://abhilashreddy.vercel.app**

My personal portfolio: experience, projects, and resume.

- Built with Next.js and Tailwind CSS, deployed on Vercel
- All profile content lives in one file, `content/profile.ts`, which the page and the JSON endpoint both read
- `/api/profile` returns the same profile as JSON

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
